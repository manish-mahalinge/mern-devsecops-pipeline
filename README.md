# Wanderlust – Travel Blog Application 🌍

A full-stack MERN travel blog application where users can explore, create, and share travel experiences.

## 🛠️ Tech Stack
- **Frontend:** React.js, TypeScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Containerization:** Docker, Docker Compose
- **CI/CD:** Jenkins

## 🚀 Features
- Create and explore travel blogs.
- Share travel experiences.
- REST API integration.
- MongoDB database connectivity.
- Docker-based application deployment.

## ⚙️ Run Locally

```bash
git clone https://github.com/YOUR_USERNAME/wanderlust.git
cd wanderlust
docker-compose up --build
```

## 🌐 Access

- Frontend: http://localhost:3000
- Backend: http://localhost:5000
